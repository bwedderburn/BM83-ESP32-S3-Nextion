BM83 ESP32-S3 Nextion

CircuitPython firmware for an ESP32-S3-based audio remote that integrates BM83 Bluetooth audio control, BLE HID input, and a Nextion display interface.

Current status: Core software flows and host-side checks are in place, with final behavior on physical hardware dependent on board wiring, display setup, and BM83 module integration.

Deployment modes

.py baseline: Use source .py files for readability and easier debugging during development.

.mpy optimized: Use compiled .mpy modules to reduce storage and improve startup/runtime behavior on constrained devices.

Validation scope

Host-based tests validate software logic and integration boundaries, but they do not replace end-to-end validation on real BM83, ESP32-S3, and Nextion hardware.
